Privacidade

Este site não usa cookies, não tem formulário e não carrega scripts de terceiros. Nenhum dado pessoal do visitante é coletado pelo autor.

A hospedagem é do GitHub Pages. Segundo o GitHub, o endereço IP de quem visita um site do GitHub Pages é registrado e guardado para fins de segurança (documentação do GitHub Pages; declaração de privacidade do GitHub).
